## Overview

A [Number](/home/how-it-fits#number) is the phone number callers
dial; it routes to whatever agent it is attached to. Phone numbers in
Unpod come from two sources:

- **Unpod Numbers** (default) - provision directly from the Unpod platform. No carrier account, no [trunk](#trunks), no SIP.
- **BYON (Bring Your Own Number)** - route numbers you already own from any provider over a [trunk](#trunks) you register once.

Once a number is in your account, you attach it to an `agent_id`. All inbound calls to that number are routed to that agent.

---

## Number Sources

| Source | Description |
|---|---|
| **Unpod** | Provision numbers directly from the Unpod platform |
| **BYON** | Bring numbers from your existing provider |

## Getting Numbers from Unpod

Numbers provisioned through Unpod are immediately available in your account. You can browse and add them from the dashboard under **Telephony → Numbers** ([Get a Number](/telephony/apis/numbers)).

Once provisioned, list them via the SDK. To see which numbers are free to
attach, use the telephony listing - its `status` is `not_assigned` only when
a number can actually be attached:

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:  # reads credentials from the environment
        for n in await client.telephony.numbers.list():
            print(n.number, n.status)   # not_assigned | assigned | closed

asyncio.run(main())
```

```text Output
+918071539102 not_assigned
+918071539118 assigned
```

<Note>
`client.telephony.*` is org-scoped: it needs `UNPOD_PLATFORM_TOKEN` and
`UNPOD_ORG_HANDLE`. A Bearer API key (`UNPOD_API_KEY`) alone is refused. A bare
`AsyncClient()` uses the platform token when `UNPOD_PLATFORM_TOKEN` is set. Set
`UNPOD_BASE_URL=https://unpod.dev` too, and export the variables or load your `.env`
yourself ([Account & keys](/home/account-and-keys)).
</Note>

## Trunks

A [Trunk](/home/how-it-fits#trunk) is your carrier connection - the SIP
capacity numbers ride on. Bring your own carrier (Twilio, Tata, …), register it
once with its SIP credentials, then work with numbers, not SIP. BYON numbers
arrive this way.

<Steps>
  <Step title="Create the trunk">
    Give it your carrier's SIP URL, credentials and the addresses it sends calls from.
  </Step>
  <Step title="Map your numbers to it">
    Mapping returns the **origin endpoint**: the host your carrier sends calls to.
  </Step>
  <Step title="Point the carrier at Unpod">
    Set the number's inbound destination in your carrier's console to that host.
  </Step>
</Steps>

The [SIP Trunking Quick Start](/telephony/quickstart) walks through each step.

### Register a trunk via the SDK

```python
from unpod import AsyncClient

client = AsyncClient()

trunk = await client.telephony.trunks.create(
    "tata-byo",
    "sip:sip.tata.in",
    username="user",
    password="secret",
    transport="tls",   # tcp (default), udp or tls
    source_ips=["203.0.113.10"],
)
mapped = await client.telephony.trunks.attach_numbers(trunk.id, [501])  # number ids
print(mapped.origin_endpoint.ingress)  # point your carrier here
```

### List and delete trunks

```python
trunks = await client.telephony.trunks.list()
await client.telephony.trunks.delete(trunk.id)
```

See [Manage Trunks](/telephony/sip-trunking/trunks) for every operation.

### Sync numbers off a trunk

```python
result = await client.numbers.sync()   # {"synced": int, "new": int}
```

One-time provisioning end to end (profile, agent, number, env vars):
[Provisioning checklist](/agent-sdk/setup-checklist).

## Listing Numbers

`client.numbers.list()` returns your organization's number records with
their ids, trunk and country - use it when you need `number_id` or
filters. To find a **free** number, use `client.telephony.numbers.list()`
as shown above.

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:  # reads credentials from the environment
        # All numbers
        numbers = await client.numbers.list()

        # Filter by status or country
        assigned = await client.numbers.list(status="assigned")
        us_numbers = await client.numbers.list(country="US")
        byon = await client.numbers.list(trunk_type="byo")

        for n in numbers:
            print(n.number_id, n.number, n.status, n.pipe_id or "unattached")

asyncio.run(main())
```

### Number fields

| Field | Type | Description |
|---|---|---|
| `number_id` | `str` | Unique number ID (`num_...`) |
| `number` | `str` | E.164 format, e.g. `+14155550100` |
| `status` | `str` | `available` (default), `assigned`, `in_call` or `disabled` |
| `trunk_type` | `str` | The type of trunk the number rides on |
| `pipe_id` | `str \| None` | The agent-voice row this number is attached to, or `None` if free. Still spelled `pipe_id` on the number record |
| `country` | `str` | ISO 3166-1 alpha-2 country code |

## Attaching a Number to an Agent

A number can be attached to exactly one agent at a time. Inbound calls to that
number are routed to that agent.

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:  # reads credentials from the environment
        number = await client.numbers.attach("num_...", "support-bot")
        print("Attached:", number.number, "-> agent support-bot")

asyncio.run(main())
```

### `attach()` parameters

| Parameter | Type | Description |
|---|---|---|
| `number_id` | `str` | The number's id (`num_...`) |
| `agent_id` | `str` | The agent to route calls to |
| `number` | `str \| None` | The E.164, optional. Pass it when `number_id` is a supervoice id so telephony can resolve the row it owns |

<Warning>
`attach()` used to take **`pipe_id=`**. It takes `agent_id` now - supervoice
stopped storing a pipe pin and resolves the pipe from the agent instead. Old
calls raise a `TypeError`.
</Warning>

`client.agents.numbers.attach(agent_id, number)` does the same job keyed by the
E.164 number rather than the number id - see [Agents](/speech-stack/agents).

## Common Patterns

### Find the first free number and attach it

```python
import asyncio
from unpod import AsyncClient

async def attach_first_free(agent_id: str) -> None:
    # telephony needs UNPOD_PLATFORM_TOKEN + UNPOD_ORG_HANDLE in the environment
    async with AsyncClient() as client:
        numbers = await client.telephony.numbers.list()
        free = [n.number for n in numbers if n.status == "not_assigned"]
        if not free:
            raise RuntimeError("No free numbers available")
        result = await client.agents.numbers.attach(agent_id, free[0])
        print(f"number={result.get('number')} agent_id={result.get('agent_id')} "
              f"status={result.get('status')}")

asyncio.run(attach_first_free("support-bot"))
```

```text Output
number=<attached_phone_number> agent_id=support-bot status=assigned
```

### Move a number to another agent

A number already attached to one of your agents moves in one call - no
detach first. With a platform token or JWT (proxy mode), inbound calls follow
it immediately.

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:  # reads credentials from the environment
        # Either: as part of an agent update
        await client.agents.update("sales-bot", number="+918071539102")

        # Or: only the number
        await client.numbers.agent.change("+918071539102", "sales-bot")

asyncio.run(main())
```

`numbers.agent.change(number, agent_id, *, attach_type=None)` takes the number
id or its E.164. `attach_type` defaults to `"pipeline"` (a Speech Stack agent);
pass `attach_type="agent"` to move the number to an agent handle such as `asst_sales`.

Only your organization's numbers can be moved (`404` otherwise). A free
number that was never attached returns `409 not_attached` from
`numbers.agent.change()` - attach it first, or use
`agents.update(number=)`, which attaches a free number for you.

<Warning>
With a Bearer API key (direct mode), `numbers.agent.change()` only sends
`PATCH /v1/numbers/{id}`: the number record names the new agent, but inbound
routing does not move. In that mode `agents.update(number=)` also doesn't attach
a free number. Use `UNPOD_PLATFORM_TOKEN` + `UNPOD_ORG_HANDLE` (or a JWT) to move
numbers.
</Warning>

### Rotate numbers across agents

```python
import asyncio
from unpod import AsyncClient

async def rotate(numbers: list[str], agents: list[str]) -> None:
    async with AsyncClient() as client:  # reads credentials from the environment
        for number, agent_id in zip(numbers, agents):
            await client.agents.update(agent_id, number=number)
            print(f"{number} -> {agent_id}")

asyncio.run(rotate(["+918071539102", "+918071539118"], ["support-bot", "sales-bot"]))
```
