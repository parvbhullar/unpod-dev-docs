**Unpod is the agentic backend for conversational AI.** Apps that talk,
remember and act: voice, messaging, agents and workflows in one SDK, on a
Context Engine that remembers every customer across every channel.

Every team building an app that talks assembles these layers from six
vendors. Unpod ships them as one system. Build the product, not the
plumbing.

<BackendStack />

## Talk

How the backend reaches the human.

- [Calling Engine](/core-engine/calling-engine) - programmable realtime
  voice: numbers, calls, SIP, transfers, streams.
- [Channels](/core-engine/channels) - voice and chat today; WhatsApp, SMS
  and email in build.
- [Models & Router](/core-engine/models-router) - STT, TTS and LLM for
  real-time turns, with automatic failover.

## Remember

The Context Engine: what survives every call, message and model swap.

- [Context Engine](/core-engine/context-engine) - one memory per customer,
  from the live turn to outcome history.
- [People & identity](/core-engine/entities) - the record every touch
  resolves to.
- [Conversations](/core-engine/conversations) - channel-neutral threads.
- [Outcomes](/core-engine/outcomes) - the structured result of every
  interaction.
- [Permissions & tenancy](/core-engine/teams-policies) - who can see and do
  what, per space and team.
- [Own your model](/core-engine/intelligence) - blocks that turn
  conversations into structure, and where that memory goes next.

## Act

What decides and performs the next step.

- [Agents](/core-engine/agent-workforce) - workers that communicate and act,
  spun up per task.
- [Agent Harness](/core-engine/agent-harness) - tools, retries, guardrails,
  human handoff, evals and observability around every agent.
- [Flows & Journeys](/core-engine/flows-journeys) - durable workflows:
  steps, waits, outcome branching.
- [Actions](/core-engine/actions) - your APIs, called mid-conversation or
  fed every outcome.
- [Events](/core-engine/events) - everything that happened, once.
- [Observability](/core-engine/observability) - call logs, recordings,
  transcripts and traces.

## Status

Every Core Engine page carries a status line. **Production** means it
carries production traffic today. **In build** means it is shipping in the
open. **Early access** means it is open to early partners. In graphics, a
**Planned** chip marks part of the design that no one can use yet. Statuses
are as of October 2026; where an API is callable today, the page links the
doc where it lives now.

## The adoption path

First call → one agent → memory of past calls → one more channel → one flow
→ a reply wakes the journey → context across every channel. Start with the
first call: [Quickstart](/get-started/quickstart).
