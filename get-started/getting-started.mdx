Unpod is the agentic backend for conversational AI: numbers, speech, agents
and memory behind one SDK. You bring the logic; Unpod runs the phone call.

## Your first hour

<Steps>
  <Step title="Get an account and a key">
    Request access, create your hub and generate an API key:
    [Account & keys](/get-started/account-and-keys).
  </Step>
  <Step title="Make your first call">
    Six SDK calls, nothing to deploy - your phone rings and an agent speaks:
    [Quickstart](/home/quickstart).
  </Step>
  <Step title="Learn the moving parts">
    Number, agent, brain, AgentRunner - each defined once:
    [Core concepts](/get-started/core-concepts).
  </Step>
  <Step title="Pick your path">
    Use the table below, then go deeper in that tab.
  </Step>
</Steps>

## Choose your path

| I want to... | Start here | You need |
|---|---|---|
| **Place a real phone call with an agent** | [Quickstart](/home/quickstart) - six SDK calls, nothing to deploy | Platform token + a number |
| Talk to an agent in the browser | [Realtime](/telephony/streaming/unpod-speech-quickstart) | A browser - runs in the hosted Playground |
| Publish an agent to a number, no code | [Phone](/agent-studio/quickstart) | A [Playground](https://app.unpod.ai/playground) account |
| Run my own Python brain on calls | [Run Your Own Brain](/agent-sdk/quickstart) | Platform token + a number |
| Call your agent like a model, over REST | [Chat API](/agent-studio/api) | Endpoint key |

Not sure? Take the **Quickstart** - it is the shortest path to something
real: your phone rings, an agent speaks, and the transcript comes back in
code.

## Where things live

| Tab | Go there when you want to |
|---|---|
| **Telephony** | Buy numbers, place and control calls, receive inbound calls, stream audio |
| **SIP Trunking** | Bring your own carrier, or connect Vapi, LiveKit, ElevenLabs, Daily or Ultravox |
| **Agent SDK** | Run your own Python brain on calls with the `unpod` SDK and AgentRunner |
| **Agent Studio** | Build, test and publish a playbook agent without code, or with SuperDialog |
| **Context** | Give agents memory: people, conversations and outcomes |
| **Guides** | Step-by-step tutorials across all of the above |

<Note>
Each path needs a different credential. [Account & keys](/get-started/account-and-keys#which-credential-is-which)
lists which one goes where.
</Note>
