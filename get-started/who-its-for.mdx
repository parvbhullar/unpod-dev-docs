Every team that needs software that talks, without building the backend.
The products differ. The backend is the same: channels, the agent harness,
models and the Context Engine underneath.

<CardGroup cols={2}>
  <Card title="Conversation-first startups" icon="rocket">
    **Launch with the backend already built.** Products where the agent is
    the interface - concierge, coaching, care, commerce. Small teams,
    millions of users, context per user.

    Buyer: founder, CTO. Start with the [Quickstart](/get-started/quickstart),
    then the [personal assistant](/apps/personal-assistant) pattern.
  </Card>
  <Card title="SaaS adding conversational features" icon="blocks">
    **Ship conversational features without rebuilding the stack.** CRM,
    support, HR, fintech and healthcare platforms reusing agents, channels
    and context across their own tenants.

    Buyer: product lead, CTO. Start with
    [Permissions & tenancy](/core-engine/teams-policies) and the
    [Quickstart](/get-started/quickstart).
  </Card>
  <Card title="Contact centers and BPOs" icon="headset">
    **More from the same team.** AI agents that place and answer calls,
    and hand off to people when it matters.

    Buyer: head of CX, operations. Start with the
    [contact center app](/apps/contact-center).
  </Card>
  <Card title="BFSI and regulated enterprises" icon="landmark">
    **Build on your own terms.** Banks, insurers and large operators who
    build rather than buy. Self-host the MIT stack inside your own boundary;
    calling-hours windows are enforced today; consent records are in build.

    Buyer: CIO, CTO. Start with
    [self-hosting](/platform/self-hosting/quickstart).
  </Card>
</CardGroup>
