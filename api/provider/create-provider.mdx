# Create Provider Configuration

Create a new telephony provider configuration by saving your provider credentials to your organization. These configurations are used to connect telephony providers to bridges.

<Note>
**Prerequisites:** Make sure you have your API Token, Org-Handle, and telephony provider credentials ready. See [Authentication](/api/get-started/authentication) for details.
</Note>

### Headers

| Name          | Type   | Required | Description                     |
|---------------|--------|----------|---------------------------------|
| Authorization | string | Yes      | API Key format: `Token <token>` |
| Org-Handle    | string | Yes      | Organization domain handle      |
| Content-Type  | string | Yes      | `application/json`              |

<Note>
Copy your `Org-Handle` from the dashboard - see [How to Get Your Organization Handle](/api/get-started/authentication#how-to-get-your-organization-handle).
</Note>

### Request Body

| Field       | Type    | Required | Description                                              |
|-------------|---------|----------|----------------------------------------------------------|
| provider    | integer | Yes      | Provider ID (`id` from [Get Telephony Providers](/api/provider/get-telephony-providers)) |
| name        | string  | No       | Configuration name                                       |
| api_key     | string  | No       | Provider API key                                         |
| api_secret  | string  | No       | Provider API secret                                      |
| base_url    | string  | No       | Provider API base URL                                    |
| sip_url     | string  | No       | Provider SIP URL                                         |

`api_key` and `api_secret` are stored but never returned in any response.

### Response Fields

| Field       | Type    | Description                      |
|-------------|---------|----------------------------------|
| status_code | integer | HTTP status code                 |
| message     | string  | Response message                 |
| data        | object  | Created provider config details  |

### Provider Config Object Fields

| Field       | Type    | Description                              |
|-------------|---------|------------------------------------------|
| Field            | Type    | Description                                          |
|------------------|---------|------------------------------------------------------|
| id               | integer | Unique provider configuration identifier             |
| name             | string  | Configuration name                                   |
| provider         | integer | Provider ID (from [Get Telephony Providers](/api/provider/get-telephony-providers)) |
| provider_details | object  | `{ id, name, description, icon }` of the provider    |
| org_handle       | string  | Handle of the owning organization                    |
| meta_json        | object  | Extra provider settings                              |
| active           | boolean | Whether the configuration is active                  |
| api_key          | string  | Always `null` - secrets are never returned           |
| api_secret       | string  | Always `null` - secrets are never returned           |
| base_url         | string  | Provider API base URL                                |
| sip_url          | string  | Provider SIP URL                                     |



## Common Error Codes

| Status Code | Description                                      |
|-------------|--------------------------------------------------|
| 201         | Created - Provider configuration created         |
| 400         | Bad Request - Invalid body, or `Org-Handle` missing or invalid |
| 401         | Unauthorized - Invalid or missing API token      |
| 403         | Forbidden - Not a member of the `Org-Handle` organization |
| 500         | Internal Server Error - Server-side error        |

## Code Examples

<CodeGroup>

```javascript Node.js
const axios = require('axios');

const headers = {
  'Authorization': 'Token your-api-token',
  'Org-Handle': 'your-org-handle',
  'Content-Type': 'application/json'
};

// Create a provider configuration
const createProvider = async (provider, name, apiKey, apiSecret) => {
  const response = await axios.post(
    'https://unpod.ai/api/v2/platform/telephony/provider-configurations/',
    { provider, name, api_key: apiKey, api_secret: apiSecret },
    { headers }
  );
  console.log(`Provider created with ID: ${response.data.data.id}`);
  return response.data.data;
};

// Example usage
createProvider(2, 'My Livekit Configuration', 'sk_xxx', 'secret_xxx');
```

```python Python
import requests

headers = {
    'Authorization': 'Token your-api-token',
    'Org-Handle': 'your-org-handle',
    'Content-Type': 'application/json'
}

def create_provider(provider: int, name: str, api_key: str, api_secret: str):
    """Create a new telephony provider configuration"""
    url = 'https://unpod.ai/api/v2/platform/telephony/provider-configurations/'
    payload = {
        'provider': provider,
        'name': name,
        'api_key': api_key,
        'api_secret': api_secret
    }
    response = requests.post(url, headers=headers, json=payload)
    data = response.json()
    print(f"Provider created with ID: {data['data']['id']}")
    return data['data']

# Example usage
create_provider(2, 'My Livekit Configuration', 'sk_xxx', 'secret_xxx')
```

## Best Practices

1. **Provider ID**: Use the `id` from the [Get Telephony Providers](/api/provider/get-telephony-providers) endpoint as `provider`
2. **Credential Security**: Never log or expose `api_key` or `api_secret` values - treat them as secrets
3. **Credential Rotation**: Use the [Update Provider](/api/provider/update-provider) endpoint to rotate credentials without deleting the configuration
4. **Configuration ID**: Store the returned `id` to reference this configuration when connecting to bridges
5. **Error Handling**: Handle 400 errors that indicate invalid credentials before they cause production issues
6. **Security**: Keep API tokens secure and rotate them regularly
