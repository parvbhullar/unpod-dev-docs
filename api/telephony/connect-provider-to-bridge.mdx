# Connect Provider to Bridge

Connect a provider configuration to a number that is already on this bridge. Calls on that number then route through the connected provider.

<Note>
**Prerequisites:** Make sure you have your API Token, a Bridge with the number on it, and a Provider Configuration ready. See [Authentication](/api/get-started/authentication) for details.
</Note>

<Note>
The number must already be on this bridge, and the provider configuration must belong to the bridge's organization.
</Note>


### Path Parameters

| Name | Type   | Required | Description                |
|------|--------|----------|----------------------------|
| slug | string | Yes      | Unique bridge slug         |

<Note>
You can get the bridge `slug` by hitting the [Get All Bridges](/api/telephony/get-all-bridges) API. The `slug` field in the response is your Bridge Slug.
</Note>

### Headers

| Name          | Type   | Required | Description                     |
|---------------|--------|----------|---------------------------------|
| Authorization | string | Yes      | API Key format: `Token <token>` |
| Org-Handle    | string | Yes      | Organization domain handle      |
| Content-Type  | string | Yes      | `application/json`              |

<Note>
Copy your `Org-Handle` from the dashboard - see [How to Get Your Organization Handle](/api/get-started/authentication#how-to-get-your-organization-handle).
</Note>

### Request Body

| Field                  | Type    | Required | Description                                                                 |
|------------------------|---------|----------|-----------------------------------------------------------------------------|
| number_id              | integer | Yes      | ID of the number on this bridge (`number_id` from [Get Bridge by Slug](/api/telephony/get-bridge-by-slug)) |
| provider_credential_id | integer | Yes      | ID of the provider configuration (`id` from [Get All Providers](/api/provider/get-all-providers)) |



### Response Fields

| Field       | Type    | Description      |
|-------------|---------|------------------|
| status_code | integer | HTTP status code |
| message     | string  | Response message |
| data        | object  | The bridge number, now linked to the provider |

### Data Object Fields

| Field                  | Type    | Description                                              |
|------------------------|---------|----------------------------------------------------------|
| id                     | integer | Bridge number ID                                         |
| number_id              | integer | Number ID                                                |
| phone_number           | string  | Phone number (E.164 format)                              |
| bridge_id              | integer | Bridge ID                                                |
| channels_count         | integer | Number of channels                                       |
| status                 | string  | Bridge number status                                     |
| agent_id               | string  | Agent the number routes to, or `null`                    |
| kind                   | string  | Termination kind: `sip` for a SIP provider configuration, otherwise `agent` |
| is_configured          | boolean | Whether the number is configured                         |
| provider_configuration | object  | The linked provider configuration. `api_key` and `api_secret` are never returned |



## Common Error Codes

| Status Code | Description                                      |
|-------------|--------------------------------------------------|
| 201         | Created - Provider linked to the number          |
| 206         | The number is not assigned or doesn't exist, or you are not a member of the bridge's organization |
| 400         | Bad Request - `number_id` or `provider_credential_id` missing, number on another bridge, provider configuration not found, or the link failed (reason in `message`) |
| 401         | Unauthorized - Invalid or missing API token      |
| 403         | Forbidden - Not a member of the `Org-Handle` organization |
| 404         | Not Found - Bridge not found                     |

## Code Examples

<CodeGroup>

```javascript Node.js
const axios = require('axios');

const headers = {
  'Authorization': 'Token your-api-token',
  'Org-Handle': 'your-org-handle',
  'Content-Type': 'application/json'
};

// Connect a provider configuration to a number on a bridge
const connectProviderToBridge = async (slug, numberId, providerCredentialId) => {
  const response = await axios.post(
    `https://unpod.ai/api/v2/platform/telephony/bridges/${slug}/connect-provider/`,
    { number_id: numberId, provider_credential_id: providerCredentialId },
    { headers }
  );
  console.log(`Linked ${response.data.data.phone_number} to provider configuration ${providerCredentialId}`);
  return response.data.data;
};

// Example usage
connectProviderToBridge('sales-bridge-001', 25, 42);
```

```python Python
import requests

headers = {
    'Authorization': 'Token your-api-token',
    'Org-Handle': 'your-org-handle',
    'Content-Type': 'application/json'
}

def connect_provider_to_bridge(slug: str, number_id: int, provider_credential_id: int):
    """Connect a provider configuration to a number on a bridge"""
    url = f'https://unpod.ai/api/v2/platform/telephony/bridges/{slug}/connect-provider/'
    payload = {
        'number_id': number_id,
        'provider_credential_id': provider_credential_id
    }
    response = requests.post(url, headers=headers, json=payload)
    data = response.json()
    print(f"Linked {data['data']['phone_number']} to provider configuration {provider_credential_id}")
    return data['data']

# Example usage
connect_provider_to_bridge('sales-bridge-001', 25, 42)
```

```bash cURL

    "provider_credential_id": 42
  }'
```

## Best Practices

1. **IDs, not strings**: Send the integer `number_id` and `provider_credential_id`, not a phone number or provider name
2. **Number on the bridge**: Confirm the number is listed on the bridge with [Get Bridge by Slug](/api/telephony/get-bridge-by-slug) before connecting
3. **Same organization**: The provider configuration must belong to the bridge's organization
4. **Error Handling**: Read `message` on 206 and 400 responses - it says which check failed
5. **Security**: Keep API tokens secure and rotate them regularly
