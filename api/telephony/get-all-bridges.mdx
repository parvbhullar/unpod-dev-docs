# Get All Bridges

Retrieve the telephony bridges in your organization that belong to the product in the `Product-Id` header. Use [Get Bridge by Slug](/api/telephony/get-bridge-by-slug) for a bridge's numbers.

<Note>
**Prerequisites:** Make sure you have your API Token and Org-Handle ready. See [Authentication](/api/get-started/authentication) for details.
</Note>

### Headers

| Name          | Type   | Required | Description                     |
|---------------|--------|----------|---------------------------------|
| Authorization | string | Yes      | API Key format: `Token <token>` |
| Org-Handle    | string | Yes      | Organization domain handle      |
| Product-Id    | string | Yes      | Product the bridges belong to, for example `unpod.ai` |

<Note>
Copy your `Org-Handle` from the dashboard - see [How to Get Your Organization Handle](/api/get-started/authentication#how-to-get-your-organization-handle).
</Note>


### Query Parameters

| Name      | Type    | Required | Description                              |
|-----------|---------|----------|------------------------------------------|
| page      | integer | No       | Page number for pagination (default = 1) |
| page_size | integer | No       | Number of bridges per page (default = 10) |

### Response Fields

| Field       | Type    | Description             |
|-------------|---------|-------------------------|
| count       | integer | Total number of bridges |
| status_code | integer | HTTP status code        |
| message     | string  | Response message        |
| data        | array   | Array of bridge objects |

### Bridge Object Fields

| Field    | Type    | Description                                  |
|----------|---------|----------------------------------------------|
| id          | integer | Bridge unique identifier                |
| name        | string  | Bridge display name                     |
| slug        | string  | Unique bridge slug identifier           |
| status      | string  | `ACTIVE`, `INACTIVE`, or `DRAFT`        |
| description | string  | Bridge description, or `null`           |


## Common Error Codes

| Status Code | Description                                      |
|-------------|--------------------------------------------------|
| 200         | Success - Bridges fetched successfully           |
| 206         | Missing `Product-Id` or `Org-Handle` header, or organization not found (reason in `message`) |
| 401         | Unauthorized - Invalid or missing API token      |
| 403         | Forbidden - Not a member of the organization     |
| 500         | Internal Server Error - Server-side error        |

## Code Examples

<CodeGroup>

```javascript Node.js
const axios = require('axios');

const headers = {
  'Authorization': 'Token your-api-token',
  'Org-Handle': 'your-org-handle',
  'Product-Id': 'unpod.ai'
};

// Get all bridges
const getAllBridges = async () => {
  const response = await axios.get(
    'https://unpod.ai/api/v2/platform/telephony/bridges/',
    { headers }
  );
  console.log(`Total bridges: ${response.data.count}`);
  response.data.data.forEach(bridge => {
    console.log(`${bridge.name} (${bridge.slug}) - ${bridge.status}`);
  });
  return response.data.data;
};

// Example usage
getAllBridges();
```

```python Python
import requests

headers = {
    'Authorization': 'Token your-api-token',
    'Org-Handle': 'your-org-handle',
    'Product-Id': 'unpod.ai'
}

def get_all_bridges():
    """Get all telephony bridges"""
    url = 'https://unpod.ai/api/v2/platform/telephony/bridges/'
    response = requests.get(url, headers=headers)
    data = response.json()
    print(f"Total bridges: {data['count']}")
    for bridge in data['data']:
        print(f"{bridge['name']} ({bridge['slug']}) - {bridge['status']}")
    return data['data']

# Example usage
get_all_bridges()
```

## Best Practices

1. **Bridge Slug**: Note each bridge's `slug` - it is used as a path parameter in other bridge endpoints
2. **Product-Id**: Send the same `Product-Id` the bridge was created with, or it won't be listed
3. **Numbers**: Bridges without numbers cannot receive inbound calls - check them with [Get Bridge by Slug](/api/telephony/get-bridge-by-slug)
4. **Error Handling**: Always handle potential errors and edge cases
5. **Security**: Keep API tokens secure and rotate them regularly
