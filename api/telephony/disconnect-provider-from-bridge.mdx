# Disconnect Provider from Bridge

Remove a number from a bridge, together with its provider link. The number is detached from the bridge and goes back to `NOT_ASSIGNED`, its provider trunk setup is removed, and its channels are released.

<Note>
**Prerequisites:** Make sure you have your API Token and Org-Handle ready. See [Authentication](/api/get-started/authentication) for details.
</Note>

### Path Parameters

| Name | Type   | Required | Description                |
|------|--------|----------|----------------------------|
| slug | string | Yes      | Unique bridge slug         |

<Note>
You can get the bridge `slug` by hitting the [Get All Bridges](/api/telephony/get-all-bridges) API. The `slug` field in the response is your Bridge Slug.
</Note>

### Headers

| Name          | Type   | Required | Description                     |
|---------------|--------|----------|---------------------------------|
| Authorization | string | Yes      | API Key format: `Token <token>` |
| Org-Handle    | string | Yes      | Organization domain handle      |
| Content-Type  | string | Yes      | `application/json`              |

<Note>
Copy your `Org-Handle` from the dashboard - see [How to Get Your Organization Handle](/api/get-started/authentication#how-to-get-your-organization-handle).
</Note>

### Request Body

| Field     | Type    | Required | Description                                                                 |
|-----------|---------|----------|-----------------------------------------------------------------------------|
| number_id | integer | Yes      | ID of the number on this bridge (`number_id` from [Get Bridge by Slug](/api/telephony/get-bridge-by-slug)) |


### Response Fields

| Field       | Type    | Description                                   |
|-------------|---------|-----------------------------------------------|
| status_code | integer | HTTP status code                              |
| message     | string  | `Provider disconnected from number <number>.` |
| data        | object  | Empty object                                  |


## Common Error Codes

| Status Code | Description                                      |
|-------------|--------------------------------------------------|
| 200         | Success - Number removed from the bridge         |
| 206         | Not a member of the bridge's organization        |
| 400         | Bad Request - `number_id` missing, or the disconnect failed (reason in `message`) |
| 401         | Unauthorized - Invalid or missing API token      |
| 403         | Forbidden - Not a member of the `Org-Handle` organization |
| 404         | Not Found - Bridge not found, or the number is not on this bridge |

## Code Examples

<CodeGroup>

```javascript Node.js
const axios = require('axios');

const headers = {
  'Authorization': 'Token your-api-token',
  'Org-Handle': 'your-org-handle',
  'Content-Type': 'application/json'
};

// Remove a number (and its provider link) from a bridge
const disconnectProviderFromBridge = async (slug, numberId) => {
  const response = await axios.post(
    `https://unpod.ai/api/v2/platform/telephony/bridges/${slug}/disconnect-provider/`,
    { number_id: numberId },
    { headers }
  );
  console.log(response.data.message);
  return response.data;
};

// Example usage
disconnectProviderFromBridge('sales-bridge-001', 25);
```

```python Python
import requests

headers = {
    'Authorization': 'Token your-api-token',
    'Org-Handle': 'your-org-handle',
    'Content-Type': 'application/json'
}

def disconnect_provider_from_bridge(slug: str, number_id: int):
    """Remove a number (and its provider link) from a bridge"""
    url = f'https://unpod.ai/api/v2/platform/telephony/bridges/{slug}/disconnect-provider/'
    payload = {'number_id': number_id}
    response = requests.post(url, headers=headers, json=payload)
    data = response.json()
    print(data['message'])
    return data

# Example usage
disconnect_provider_from_bridge('sales-bridge-001', 25)
```

```bash cURL
# Remove a number (and its provider link) from a bridge
curl -X POST "https://unpod.ai/api/v2/platform/telephony/bridges/sales-bridge-001/disconnect-provider/" \
  -H "Authorization: Token your-api-token" \
  -H "Org-Handle: your-org-handle" \
  -H "Content-Type: application/json" \
  -d '{
    "number_id": 25
  }'
```

## Best Practices

1. **Pre-disconnect Check**: Confirm the number is on the bridge with [Get Bridge by Slug](/api/telephony/get-bridge-by-slug) and use its `number_id`
2. **Number leaves the bridge**: This removes the number from the bridge, not only the provider link - to use it again, add it back to a bridge
3. **Service Disruption**: Calls on the number stop routing through the bridge immediately
4. **Error Handling**: Handle 404 - the number may already be off the bridge
5. **Security**: Keep API tokens secure and rotate them regularly
