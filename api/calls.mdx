# Calls API

Create and manage voice calls. A call binds a [Speech Pipe](/speech/pipes) to a
phone number and an `AgentRunner`: outbound calls are initiated through this
API, inbound calls are created automatically when someone dials an attached
number.

All endpoints require a Bearer API key:

```http
Authorization: Bearer sk-...
```

---

## Create an Outbound Call

Enqueue a new outbound call.

```http
POST /v1/calls
```

<Note>
`POST /v1/calls` is **asynchronous**. It records the call, returns `201` with
`status="pending"`, and enqueues it. The call is dispatched on a worker once
your account has a free concurrency slot, then advances
`pending → ringing → active → completed`. Poll `GET /v1/calls/{call_id}` or use
[hooks](/speech/hooks-events) to track progress. See
[Call Lifecycle](/speech/call-lifecycle) for the full state model.
</Note>

### Request Body

| Parameter      | Type     | Required | Description                                                                 |
|----------------|----------|----------|-----------------------------------------------------------------------------|
| `pipe_id`      | `string` | Yes      | Speech Pipe to run the call on (`pipe_...`)                                 |
| `to_number`    | `string` | Yes      | Destination number in E.164 format                                         |
| `from_number`  | `string` | No       | Caller ID. Defaults to the number attached to the Speech Pipe. `400` if neither is set |
| `instructions` | `string` | No       | Per-call instruction override, surfaced to the agent as `ctx.instructions` |
| `data`         | `object` | No       | Arbitrary per-call metadata, surfaced to the agent as `ctx.data`           |

Number resolution order: `from_number` override → the Speech Pipe's attached
number → `400 no_from_number`.

### Example Request

```http
POST /v1/calls
Authorization: Bearer sk-...
Content-Type: application/json

{
  "pipe_id": "pipe_xyz",
  "to_number": "+14155551234",
  "from_number": "+18005551234",
  "instructions": "Customer prefers Hindi. Confirm the appointment.",
  "data": { "customer_id": "C123", "appointment": "2026-06-10 09:30" }
}
```

### Response — `201 Created`

```json
{
  "call_id": "SCL_abc123def456",
  "project_id": "proj_123",
  "pipe_id": "pipe_xyz",
  "direction": "outbound",
  "from_number": "+18005551234",
  "to_number": "+14155551234",
  "number_id": "num_001",
  "trunk_id": "trunk_001",
  "session_id": null,
  "room_name": null,
  "instructions": "Customer prefers Hindi. Confirm the appointment.",
  "data": { "customer_id": "C123", "appointment": "2026-06-10 09:30" },
  "started_at": "2026-06-15T12:00:00Z",
  "ended_at": null,
  "duration_s": null,
  "status": "pending",
  "end_reason": null,
  "created": "2026-06-15T12:00:00Z",
  "modified": "2026-06-15T12:00:00Z"
}
```

`session_id` and `room_name` are `null` at creation; they are populated once
the call is dispatched and reaches `ringing`.

## Get a Call

Retrieve a single call by ID.

```http
GET /v1/calls/{call_id}
```

### Response — `200 OK`

Returns the same call object as the create response, reflecting the current
`status`, `session_id`/`room_name` (once dispatched), and `duration_s`/
`end_reason` (once ended).

```json
{
  "call_id": "SCL_abc123def456",
  "project_id": "proj_123",
  "pipe_id": "pipe_xyz",
  "direction": "outbound",
  "from_number": "+18005551234",
  "to_number": "+14155551234",
  "session_id": "sess_789",
  "room_name": "pipe_xyz-3f9a1c2b",
  "status": "active",
  "started_at": "2026-06-15T12:00:05Z",
  "ended_at": null,
  "duration_s": null,
  "end_reason": null,
  "created": "2026-06-15T12:00:00Z",
  "modified": "2026-06-15T12:00:07Z"
}
```

Returns `404 call_not_found` if no call matches the ID in your project.

## List Calls

List calls for your project, optionally filtered.

```http
GET /v1/calls
```

### Query Parameters

| Parameter     | Type     | Required | Description                                                              |
|---------------|----------|----------|--------------------------------------------------------------------------|
| `call_status` | `string` | No       | Filter by status: `pending`, `ringing`, `active`, `completed`, `failed`, `cancelled` |
| `pipe_id`     | `string` | No       | Filter by Speech Pipe                                                    |

### Response — `200 OK`

Returns a JSON array of call objects (most recent first, up to 500).

```json
[
  {
    "call_id": "SCL_abc123def456",
    "pipe_id": "pipe_xyz",
    "direction": "outbound",
    "to_number": "+14155551234",
    "status": "completed",
    "duration_s": 85,
    "end_reason": "hangup",
    "started_at": "2026-06-15T12:00:05Z",
    "ended_at": "2026-06-15T12:01:30Z"
  }
]
```

## Hang Up a Call

End an in-progress call. Valid only while the call is `pending`, `ringing`, or
`active`.

```http
POST /v1/calls/{call_id}/hangup
```

### Response — `200 OK`

```json
{
  "call_id": "SCL_abc123def456",
  "status": "completed",
  "end_reason": "hangup",
  "ended_at": "2026-06-15T12:02:00Z",
  "modified": "2026-06-15T12:02:00Z"
}
```

Returns `409 call_not_active` if the call has already ended, or
`404 call_not_found` if no call matches the ID in your project.

---

## Call Statuses

| Status      | Meaning                                                        |
|-------------|----------------------------------------------------------------|
| `pending`   | Enqueued; waiting for a free concurrency slot (outbound only). |
| `ringing`   | Dispatched; the SIP leg is dialing/ringing.                    |
| `active`    | Connected; audio is flowing between caller and agent.          |
| `completed` | Ended normally.                                                |
| `failed`    | Ended due to an error (see `end_reason`).                      |
| `cancelled` | Cancelled before connecting.                                   |

---

## Error Responses

| Status | Error Code         | Description                                                                 |
|--------|--------------------|-----------------------------------------------------------------------------|
| 400    | `no_from_number`   | No `from_number` provided and the Speech Pipe has no attached number        |
| 401    | `invalid_api_key`  | Missing or invalid Bearer API key                                           |
| 404    | `pipe_not_found`   | `pipe_id` does not exist in your project                                    |
| 404    | `call_not_found`   | No call matches the given `call_id` in your project                         |
| 409    | `call_not_active`  | Hangup requested on a call that has already ended                           |
| 503    | `media_unavailable`| No healthy media backend could serve the call; the call is finalized `failed` with `end_reason="media_unavailable"` |

## SDK Equivalents

The [Python SDK](/sdk/setup-checklist) wraps these endpoints:

```python
from unpod import AsyncClient

async with AsyncClient(api_key="sk-...") as client:
    # Create (enqueues; returns status="pending")
    call = await client.calls.create(
        pipe_id="pipe_xyz",
        to_number="+14155551234",
        instructions="Confirm the appointment.",
        data={"customer_id": "C123"},
    )

    # Poll for status
    call = await client.calls.get(call.call_id)

    # List
    active = await client.calls.list(status="active", pipe_id="pipe_xyz")

    # Hang up
    await client.calls.hangup(call.call_id)
```
