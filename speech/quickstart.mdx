## Prerequisites

- **Python 3.11+**
- An Unpod API key (see Step 2)

<Note>
**Local development:** the production API at `wss://api.unpod.io` is not yet live.
Until it is, run `supervoice` locally and point the SDK at it by overriding
`base_url` (the SDK defaults to `wss://api.unpod.io`):

```bash
# Terminal 1 — start the backend
cd supervoice && uv run uvicorn supervoice.main:app --port 8000 --reload
```

Then pass `base_url="ws://127.0.0.1:8000"` to `AgentRunner(...)` and set
`UNPOD_SERVICE_BASE_URL="http://localhost:8000/platform"` for the management client.
</Note>

## Step 1 - Install the SDK

```bash
pip install unpod superdialog
```

Or with `uv`:

```bash
uv add unpod superdialog
```

---

## Step 2 - Set Your API Key

The SDK reads your credentials from the environment. Set them once — every
`AsyncClient()` and `AgentRunner(...)` below picks them up automatically, so you
never hardcode keys in your code.

```bash
export UNPOD_API_KEY="sk-..."
```

Or add them to a `.env` file and load it with `python-dotenv`:

```bash
# .env
UNPOD_API_KEY=sk-...
```

---

## Step 3 - Pick a Voice Profile

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:
        profiles = await client.voice_profiles.list(language="en")
        for p in profiles:
            print(p.id, p.name, p.gender, p.quality)

asyncio.run(main())
```

Example output:
```
vp_en_female_hd   Emma (HD)    female  high
vp_en_male_std    James (Std)  male    standard
```

---

## Step 4 - Create a Speech Pipe

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:
        pipe = await client.pipes.create(
            name="Support Bot",
            voice_profile="vp_en_female_hd",
            agent_id="my-agent",   # the name you give your AgentRunner (Step 7)
            recording=True,
            max_call_duration_s=600,
        )
        print("Pipe ID:", pipe.pipe_id)

asyncio.run(main())
```

<Note>
Save the `pipe.pipe_id` - you will use it in the steps below.
</Note>

---

## Step 5 - Build a Dialog Flow

Both paths use the same conversation logic. Create a flow once and save it to a
file your entrypoint will load:

```python
import asyncio
from superdialog import create_dialog_flow

async def main():
    flow = await create_dialog_flow(
        prompt=(
            "You are Alex, a friendly support agent. "
            "Greet the user, ask how you can help, resolve their issue, "
            "and end the conversation when done."
        ),
        llm="anthropic/claude-haiku-4-5",
    )
    flow.save("support.json")

asyncio.run(main())
```

This writes `support.json`, which the entrypoint loads with
`Flow.load("support.json")` in the next step.

## Telephony Path

### Step 6T - Attach a Phone Number

```python
import asyncio
from unpod import AsyncClient

PIPE_ID = "pipe_..."
NUMBER_ID = "num_..."   # from client.numbers.list()

async def main():
    async with AsyncClient() as client:
        number = await client.numbers.attach(NUMBER_ID, PIPE_ID)
        print("Attached:", number.number, "->", number.pipe_id)

asyncio.run(main())
```

See [Phone Numbers](/speech/numbers) for how to list, provision, or bring your own number.

### Step 7T - Write Your Entrypoint

Create `agent.py`. The `agent_id` is a name **you choose** — it just has to match
the `agent_id` you set on the Speech Pipe in Step 4. There is no separate
"create an agent" step or dashboard-generated ID.

```python
from superdialog import DialogMachine, Flow
from unpod import AgentRunner, CallContext

flow = Flow.load("support.json")  # created in Step 5

async def handle_call(ctx: CallContext) -> None:
    ctx.session.dialog_machine = DialogMachine(
        flow=flow,
        llm="anthropic/claude-haiku-4-5",
    )
    await ctx.session.say("Hello, thanks for calling!")
    await ctx.session.run()

AgentRunner(
    entrypoint=handle_call,
    agent_id="my-agent",            # must match the pipe's agent_id
    max_sessions=10,
    base_url="ws://127.0.0.1:8000",  # local dev; remove in production
).start()
```

### Step 8T - Run and Call

```bash
python agent.py
```

Call the number you attached. The runner connects to the Unpod orchestrator and dispatches inbound calls to your entrypoint.

```
[Unpod] AgentRunner registered  agent_id=my-agent capacity=10
[Unpod] Call dispatched         session_id=ses_...
[Unpod] Call ended              duration=47s
```

## Web / App Path

### Step 6W - Create a Session Token

Your backend generates a short-lived session token for each user. The browser uses this token to connect.

```python
import asyncio
from unpod import AsyncClient

async def create_session(pipe_id: str, user_id: str) -> str:
    async with AsyncClient() as client:
        token = await client.sessions.create_token(
            pipe_id=pipe_id,
            metadata={"user_id": user_id},
        )
        return token.token

asyncio.run(create_session("pipe_...", "usr_123"))
```

Return this token to your frontend. Tokens are single-use and expire after 60 seconds.

### Step 7W - Embed the Web SDK

Install the browser SDK:

```bash
npm install @unpod/web-sdk
```

Connect from your frontend:

```typescript
import { UnpodSession } from "@unpod/web-sdk";

const session = new UnpodSession({
  token: "<token-from-your-backend>",
});

await session.connect();   // starts microphone + speaker
session.on("agent_reply", (text) => console.log("Agent:", text));
session.on("user_turn", (text) => console.log("User:", text));

// End the session
await session.disconnect();
```

The same `AgentRunner` entrypoint from Step 7T handles both phone and browser sessions - no changes needed.

### Step 8W - Run Your Agent

```bash
python agent.py
```

The runner accepts sessions from both telephony and web SDK connections on the same `agent_id`.
