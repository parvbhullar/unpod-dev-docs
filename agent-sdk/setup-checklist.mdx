Before your first call routes to your agent, complete these four steps once.

The scripts read `UNPOD_BASE_URL`, `UNPOD_PLATFORM_TOKEN` and `UNPOD_ORG_HANDLE`
from the environment (see [Environment Variables](#environment-variables)).
`export` them, or keep them in a `.env` file and call
`from dotenv import load_dotenv; load_dotenv()` at the top of each script - the
SDK does not reliably find `.env` in your working folder on its own.

## 1. Pick a Voice Profile

```python
import asyncio
from unpod import AsyncClient

async def list_profiles():
    client = AsyncClient()
    profiles = await client.voice_profiles.list()
    for p in profiles:
        print(p.profile_id, p.name)

asyncio.run(list_profiles())
```

Copy a profile `name` or `profile_id` for step 2. See
[Voice Profiles](/agent-sdk/voice-profiles) for filtering and fields.

## 2. Create an Agent

```python
import asyncio
from unpod import AsyncClient, Runner

async def create_agent():
    client = AsyncClient()
    voice = await client.agents.voice.create(
        "my-agent",                        # agent_id - MUST match AgentRunner(agent_id=...)
        brain=Runner(),                    # this checklist runs its own worker
        name="My Agent",
        voice_profile="Riya",              # a profile name or profile_id from step 1
    )
    print(voice.agent_id, voice.voice_profile_name)
    return voice

asyncio.run(create_agent())
```

<Warning>
**`agent_id` is a string you choose, and it must match everywhere.**

The `agent_id` you pass here must exactly match `AgentRunner(agent_id=...)` in
step 4. Mismatching them is the most common first-run failure - the call arrives
and no runner claims it.
</Warning>

Other options (`greeting`, `recording`, `max_call_duration_s`, `max_concurrent`)
and the other three brain sources are in [Agents](/speech-stack/agents).

## 3. Attach a Phone Number

Numbers attach to an **`agent_id`**, not to a pipe id.

```python
import asyncio
from unpod import AsyncClient

async def assign_number(agent_id: str) -> None:
    client = AsyncClient()
    numbers = await client.telephony.numbers.list()
    free = [n.number for n in numbers if n.status == "not_assigned"]
    if not free:
        print("No free numbers. Provision one in the Unpod dashboard first.")
        return
    await client.agents.numbers.attach(agent_id, free[0])
    print(f"Attached {free[0]}")

asyncio.run(assign_number("my-agent"))
```

<Note>
A number with `status == "not_assigned"` is free to attach. `client.numbers.attach(number_id, agent_id)`
does the same thing keyed by the number id instead of the E.164 number (it used
to take `pipe_id=`; it takes `agent_id` now).
</Note>

No numbers yet, or bringing your own carrier? See
[Phone Numbers](/speech-stack/numbers) and [Trunks](/speech-stack/numbers#trunks).

## 4. Start Your Runner

```python
from unpod import AgentRunner, CallContext

async def entrypoint(ctx: CallContext) -> None:
    # set ctx.session.dialog_machine to your brain - see Bring Your Agent
    await ctx.session.say("Hello, thanks for calling!")
    await ctx.session.run()

AgentRunner(
    entrypoint=entrypoint,
    agent_id="my-agent",   # must match the agent_id from step 2
).start()
```

## Full Setup Script

```python
import asyncio
from unpod import AsyncClient, Runner

async def setup():
    client = AsyncClient()

    # 1. Pick a voice profile
    profiles = await client.voice_profiles.list()
    profile = profiles[0]

    # 2. Create the agent
    voice = await client.agents.voice.create(
        "my-agent",
        brain=Runner(),
        name="My Agent",
        voice_profile=profile.profile_id,
    )

    # 3. Attach the first free number
    numbers = await client.telephony.numbers.list()
    free = [n.number for n in numbers if n.status == "not_assigned"]
    if free:
        await client.agents.numbers.attach("my-agent", free[0])

    print(f"Agent created: {voice.agent_id}")
    print(f"Number: {free[0] if free else 'none assigned'}")

asyncio.run(setup())
```

Then start your runner in a separate process:

```python
from unpod import AgentRunner, CallContext
from unpod.adapters.langchain import LangChainAdapter

from your_app import your_chain   # your LangChain Runnable

async def entrypoint(ctx: CallContext) -> None:
    ctx.session.dialog_machine = LangChainAdapter(your_chain)
    await ctx.session.run()

AgentRunner(entrypoint=entrypoint, agent_id="my-agent").start()
```

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `UNPOD_PLATFORM_TOKEN` | Yes | Your API key (platform token) from **Settings → Access → API keys**. Used by `AsyncClient`/`Client` (proxy mode) **and required by the `AgentRunner`** to register with the orchestrator |
| `UNPOD_ORG_HANDLE` | Yes | Your org handle, sent with the token. Required by the `AgentRunner` and by org-scoped calls (telephony, analytics, voice profiles) |
| `UNPOD_BASE_URL` | Yes | Shared host, e.g. `https://unpod.dev`. The SDK derives every endpoint from it, including the runner's `wss://<host>`. The built-in default host does not resolve, so always set it |
| `UNPOD_SERVICE_BASE_URL` | No | Management REST override only. Leave it unset; the SDK derives it from `UNPOD_BASE_URL` |
| `UNPOD_API_KEY` | No | Direct-mode Bearer key (`sk_...`). Management-client fallback when `UNPOD_PLATFORM_TOKEN` is unset; cannot reach telephony or analytics. The `AgentRunner` no longer accepts it |
| `UNPOD_ORCHESTRATOR_URL` | No | Runner WebSocket override only. Takes precedence over `UNPOD_BASE_URL` when set |

### Which URL setting to use

- `UNPOD_BASE_URL` - management API and runner share one host.
- `UNPOD_SERVICE_BASE_URL` - management REST override only.
- `UNPOD_ORCHESTRATOR_URL` - runner WebSocket override only.
- `base_url=` / `orchestrator_base_url=` in code - one script or test overrides `.env`.

Production values and the `serve`-transport extras: [Deploy](/agent-sdk/deploy).
