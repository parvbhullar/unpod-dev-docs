Unpod is infrastructure, so the products built on it differ: a contact
center, a personal assistant, an email-first agent. Underneath, every one
of them uses the same six layers.

## Which layers each app uses

| Layer | Contact center | Personal assistant | Email-first agent |
|---|---|---|---|
| Telephony | Yes | Yes | For the call step |
| Channels | Voice | Voice, chat, WhatsApp\* | Email\*, voice |
| Models | Yes | Yes | Yes |
| Context Engine | Per call | Across channels\* | Across channels\* |
| Agents | Yes | Yes | Yes |
| Actions | Sheets, webhooks | Your APIs | Your APIs |

\* In build - each app page says what it waits on.
