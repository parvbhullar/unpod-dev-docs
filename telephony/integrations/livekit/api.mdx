The **programmatic** path: list providers → create a LiveKit configuration → connect
it to your Bridge. Prefer clicks? See the [Dashboard guide](/telephony/integrations/livekit/dashboard).

<Note>
**Base URL:** `https://unpod.ai/api/v2/platform/`
Every request needs `Authorization: Token <your-api-key>` and an `Org-Handle` header.
See [Authentication](/api/get-started/authentication).
</Note>

## Prerequisites

- An Unpod **API Token** and **Org-Handle**.
- A **Bridge** with a number attached — note its `slug`.
- LiveKit **API Key**, **API Secret**, **Base URL**, and **SIP URL** from `cloud.livekit.io`.

## 1. Find the LiveKit provider

```bash cURL
curl https://unpod.ai/api/v2/platform/telephony/providers/ \
  -H "Authorization: Token $UNPOD_TOKEN" \
  -H "Org-Handle: $ORG_HANDLE"
```

```json Response
{
  "status_code": 200,
  "data": [ { "id": 4, "name": "LiveKit", "slug": "livekit" } ]
}
```

## 2. Create the LiveKit provider configuration

LiveKit needs a key **and** secret. Pass the API key as `account_sid` and the secret
as `auth_token`; include the URLs in `metadata`.

<CodeGroup>
```bash cURL
curl -X POST https://unpod.ai/api/v2/platform/telephony/providers-configurations/ \
  -H "Authorization: Token $UNPOD_TOKEN" \
  -H "Org-Handle: $ORG_HANDLE" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "livekit",
    "account_sid": "<LIVEKIT_API_KEY>",
    "auth_token": "<LIVEKIT_API_SECRET>",
    "metadata": {
      "base_url": "wss://your-project.livekit.cloud",
      "sip_url": "sip:your-project.sip.livekit.cloud"
    }
  }'
```
```python Python
import requests

H = {"Authorization": f"Token {TOKEN}", "Org-Handle": ORG_HANDLE,
     "Content-Type": "application/json"}
payload = {
    "provider": "livekit",
    "account_sid": LIVEKIT_API_KEY,
    "auth_token": LIVEKIT_API_SECRET,
    "metadata": {
        "base_url": "wss://your-project.livekit.cloud",
        "sip_url": "sip:your-project.sip.livekit.cloud",
    },
}
r = requests.post(
    "https://unpod.ai/api/v2/platform/telephony/providers-configurations/",
    headers=H, json=payload)
config_id = r.json()["data"]["id"]
```
</CodeGroup>

```json Response (201)
{
  "status_code": 201,
  "message": "Provider configuration created successfully.",
  "data": { "id": 43, "provider": "livekit", "created_at": "2026-02-07T10:00:00Z" }
}
```

## 3. Connect the configuration to your Bridge

```bash cURL
curl -X POST \
  https://unpod.ai/api/v2/platform/telephony/bridges/$BRIDGE_SLUG/connect-provider/ \
  -H "Authorization: Token $UNPOD_TOKEN" \
  -H "Org-Handle: $ORG_HANDLE" \
  -H "Content-Type: application/json" \
  -d '{ "provider_config_id": 43 }'
```

The number on that Bridge now streams over LiveKit SIP.

<Note>
Want to drive the LiveKit pipeline directly in Python instead of via SIP trunking?
Use the native [LiveKit embedding guide](/superdialog/embedding-guides/livekit) with
the `DialogMachineLLM` plugin.
</Note>

## Troubleshooting

| Status | Meaning | Fix |
|---|---|---|
| `400` | Bad credentials / URLs | Re-check key, secret, `base_url`, `sip_url` |
| `401` | Bad Unpod token | Verify `Authorization: Token …` |
| `409` | Config already exists | Reuse the existing `provider_config_id` |
