The **programmatic** path: copy your Unpod number's outbound SIP credentials, then call **Ultravox's Create Agent Call** endpoint
with those SIP details. Ultravox places the outbound call through your Unpod number. Prefer
clicks? See the [Dashboard guide](/telephony/integrations/ultravox/dashboard).

<Note>
**Unpod Base URL:** `https://unpod.dev/api/v2/platform/`
Every Unpod request needs `Authorization: Token <your-api-key>` and an `Org-Handle` header.
See [Authentication](/api/get-started/authentication).
</Note>

## Prerequisites

- An Unpod **API Token** and **Org-Handle**, plus a number in your org.
- An Ultravox **API key** and an **agent** (note its **Agent ID**).

## 1. Find your Unpod number

```bash cURL
curl "https://unpod.dev/api/v2/platform/telephony/numbers/?include_assigned=true" \
  -H "Authorization: Token $UNPOD_PLATFORM_TOKEN" \
  -H "Org-Handle: $UNPOD_ORG_HANDLE"
```

```json Response (200)
{
  "status_code": 200,
  "message": "Telephony numbers fetched successfully.",
  "data": [
    { "id": 501, "number": "+918071539111", "state": "ASSIGNED", "active": true }
  ]
}
```

## 2. Get your number's outbound SIP credentials

Ultravox places the call through your number's **outbound trunk**. Unpod creates it, with a
generated username and password, when you connect the number to a SIP trunk in the
dashboard. The API doesn't return these credentials: copy them from
**Outbound Trunk Details**
([Connect an Unpod Number](/telephony/integrations/unpod/dashboard#outbound-trunk)).

You now have everything Ultravox needs:
- **SIP domain** - the outbound trunk **Address**, `sip-lb1.unpod.tel`.
- **Username** / **Password** - from **Outbound Trunk Details**.
- Your **number** (`+918071539111`) for caller ID.

## 3. Place the call from Ultravox

This is **Ultravox's own API** (`api.ultravox.ai`, `X-API-Key` header). Point `to` at your
Unpod SIP domain and pass the Unpod credentials.

```bash cURL
curl -X POST https://api.ultravox.ai/api/agents/YOUR_AGENT_ID/calls \
  -H "X-API-Key: YOUR_ULTRAVOX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "medium": {
      "sip": {
        "outgoing": {
          "to": "sip:+919999999999@sip-lb1.unpod.tel",
          "from": "+918071539111",
          "username": "<username from Outbound Trunk Details>",
          "password": "<password from Outbound Trunk Details>"
        }
      }
    },
    "firstSpeakerSettings": { "user": {} }
  }'
```

| Field | Value |
|---|---|
| `to` | Destination as `sip:<number>@<your-unpod-sip-domain>` |
| `from` | Your Unpod number (caller ID) |
| `username` / `password` | From your number's **Outbound Trunk Details** (step 2) |
| `firstSpeakerSettings` | `{ "user": {} }` - callee speaks first (outbound) |

Ultravox returns a `callId` and sends the SIP INVITE through Unpod. The agent joins when
the callee answers.

## 4. Debug with SIP logs

If a call is rejected, pull Ultravox's SIP logs for that `callId`:

```bash cURL
curl https://api.ultravox.ai/api/calls/CALL_ID/sip/logs \
  -H "X-API-Key: YOUR_ULTRAVOX_API_KEY"
```

## Troubleshooting

| Status | Meaning | Fix |
|---|---|---|
| `403` | Auth rejected by Unpod | Re-check `username` / `password` (from **Outbound Trunk Details**, step 2) |
| `407` | Proxy auth required | Ensure `username` / `password` are in `sip.outgoing` |
| `480` | Destination unavailable | Verify the `to` number; confirm your Unpod number is active |
| `401` (Unpod) | Bad Unpod token | Verify `Authorization: Token …` on Unpod calls |
