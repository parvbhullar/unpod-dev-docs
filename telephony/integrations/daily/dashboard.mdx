The **no-code** path. Configure Daily as a provider in the Unpod Studio and bind it
to a number for multi-party, web-based voice and video. Prefer code? See the
[API guide](/telephony/integrations/daily/api).

<Note>
**You need:** an Unpod number on a Bridge, and a Daily account with an **API Key**
(Daily Dashboard → Developers).
</Note>

## Configure the number with Daily

<Steps>
  <Step title="Open Configure on your number">
    The number is already on your Bridge. Click **Configure** to activate the integration.
  </Step>
  <Step title="Choose a provider">
    You are redirected to the provider picker. Click **Configure** in front of **Daily**.
  </Step>
  <Step title="Enter your Daily credentials">
    Fill the mandatory fields:
    - **Name** - any label for this configuration.
    - **API Key** - your Daily API key, used to access Daily's services.
  </Step>
  <Step title="Copy the API key from Daily">
    In the **Daily Dashboard**, go to **Developers**, copy the **API Key**, and paste
    it into the portal.
  </Step>
  <Step title="Verify and Configure">
    Click **Verify and Configure**. The configuration appears under **Active Providers**.
  </Step>
  <Step title="Attach the provider to your number">
    Click **Select** next to your Daily configuration under **Active Providers**.
  </Step>
  <Step title="Set channels and agent">
    Open **Settings** and submit:
    - **Concurrency Channels** - simultaneous sessions allowed.
    - **Enter Agent** - the agent that drives the session.
  </Step>
  <Step title="Publish">
    Click **Publish** at the top of the dashboard. The number is ready to use.
  </Step>
</Steps>

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| Verify fails | Wrong API key | Re-copy from Daily Dashboard → Developers |
| No media | Room/region misconfigured | Check the Daily domain and region settings |
| Agent silent | No agent bound | Set **Enter Agent** in Settings |
