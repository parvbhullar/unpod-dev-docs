Unpod is built ground-up for **AI-first interconnectivity**. Telephony brings the
audio in over SIP or WebSocket; the speech stack transcribes and synthesizes it;
your brain drives the conversation. Every layer is provider-agnostic — swap one
without touching the rest.

<Note>
You compose four independent layers: **carrier** (who delivers the call) →
**voice runtime** (where the pipeline runs) → **speech** (STT + TTS) → **brain**
(what generates the reply). Pick best-of-breed at each layer; Unpod wires them
together and fails over automatically.
</Note>

## Telephony / SIP carriers

Unpod is BYO-carrier. Create a trunk with your carrier credentials, attach
numbers, and inbound calls reach your agents.

| Carrier | How | Status |
|---|---|---|
| **Any SIP trunk** (Twilio, Telnyx, Plivo, Vonage, SignalWire, your SBC…) | [Create a trunk](/telephony/trunks/create-trunk) with `sip_url` + auth + source-IP allow-list | GA |
| **Twilio** | Elastic SIP Trunking → point at your Unpod origin endpoint | GA |
| **LiveKit SIP** | Native LiveKit SIP gateway (inbound via webhook or poller) | GA |

## LLMs

Brains backed by a raw model resolve through three swappable backends — pick by
URI prefix or env. The default reaches 100+ providers.

| Backend | Selector | Reaches |
|---|---|---|
| **any-llm** | `anyllm/` (default) | Official provider SDKs — `anthropic/`, `openai/`, `google/`, `groq/`… |
| **LiteLLM** | `litellm/` | 100+ providers, plus `vllm/`, `ollama/`, `custom/` |
| **OpenAI native** | `oai/` | OpenAI API, LiveKit inference gateway, OpenAI-compatible endpoints |

Common model URIs: `anthropic/claude-haiku-4-5`, `openai/gpt-4.1-mini`,
`google/gemini-*`, `groq/llama-*`. Resilience (timeout / retry / cross-provider
hedge) wraps any of them.

## Dialog brains

The brain slot is `ctx.session.dialog_machine`. Assign any of these — all
importable from `unpod.adapters` — or any object satisfying the
[`DialogAdapter` protocol](/speech-stack/adapters#the-dialogadapter-protocol).

<CardGroup cols={3}>
  <Card title="SuperDialog" icon="sparkles" href="/superdialog/introduction">
    Playbook-driven agent. Auto-wrapped. `pip install unpod[dialog]`
  </Card>
  <Card title="Anthropic" icon="bot" href="/speech-stack/adapters#bundled-adapters">
    Wrap an `AsyncAnthropic` client. Real token streaming.
  </Card>
  <Card title="OpenAI" icon="bot" href="/speech-stack/adapters#bundled-adapters">
    Wrap an `AsyncOpenAI` client. Streams via Chat Completions.
  </Card>
  <Card title="LangChain" icon="link" href="/speech-stack/adapters#bundled-adapters">
    Any `Runnable` (chain, agent, graph). `pip install unpod[langchain]`
  </Card>
  <Card title="HTTP brain" icon="webhook" href="/speech-stack/adapters#bundled-adapters">
    Any language — point at a remote endpoint. Ships in base `unpod`.
  </Card>
  <Card title="MCP server" icon="network" href="/speech-stack/adapters#bundled-adapters">
    Model Context Protocol server as a brain. `unpod[mcp]` *(preview)*
  </Card>
</CardGroup>

| Adapter | Constructor | Wraps | Install |
|---|---|---|---|
| `SuperDialogAdapter` | `(dm)` | superdialog `DialogMachine` / `LLMAgent` | `unpod[dialog]` |
| `AnthropicAdapter` | `(client, model="claude-haiku-4-5-20251001", system_prompt=None, max_tokens=1024)` | `anthropic.AsyncAnthropic` | `anthropic` |
| `OpenAIAdapter` | `(client, model="gpt-4o-mini", system_prompt=None)` | `openai.AsyncOpenAI` | `openai` |
| `LangChainAdapter` | `(chain, input_key="messages")` | LangChain `Runnable` | `unpod[langchain]` |
| `HTTPAdapter` | `(url, headers=None, timeout_s=10.0)` | Remote HTTP endpoint | base `unpod` |
| `MCPAdapter` | `(server_url, tools=None, llm="anthropic/claude-haiku-4-5", headers=None)` | MCP server *(preview)* | `unpod[mcp]` |

Any object with `turn()` / `stream()` / `assist()` is a valid brain — the protocol
is `@runtime_checkable`, no base class required. Slack bots, Discord agents, and
proprietary engines plug in the same way.

## Prerequisites

<Steps>
  <Step title="API credentials">
    An **API Token** and **Org-Handle**. See [Authentication](/api/get-started/authentication).
  </Step>
  <Step title="A number routed to an agent">
    Bring a number and attach it to a trunk → agent. See the [Quickstart](/telephony/quickstart).
  </Step>
  <Step title="The SDK installed">
    `pip install unpod` plus the extra for your brain (`unpod[dialog]`, `unpod[langchain]`, `unpod[mcp]`).
  </Step>
  <Step title="A voice profile">
    Pick STT + TTS by selecting a [Voice Profile](/speech-stack/voice-profiles) — no provider keys needed.
  </Step>
</Steps>

## Choose your integration

| If you want to… | Carrier | Runtime | Brain |
|---|---|---|---|
| Ship a playbook-driven agent fast | any SIP | Unpod Voice | **SuperDialog** |
| Drive a call with a raw Claude / GPT | any SIP | Unpod Voice / LiveKit | **Anthropic** / **OpenAI** |
| Reuse an existing LangChain chain | any SIP | any | **LangChain** |
| Keep logic in another language | any SIP | any | **HTTP brain** |
| Orchestrate tools via MCP | any SIP | any | **MCP** *(preview)* |
| Run the lowest-latency phone pipeline | any SIP | **LiveKit** | any |
| Build a text / web chatbot | — | **FastAPI** | any |

<Warning>
`session.run()` calls only `stream()`. A single-chunk `stream()` fallback
produces choppy, high-latency audio. Implement real token streaming — see
[Streaming is the hot path](/speech-stack/bring-your-agent#streaming-is-the-hot-path).
</Warning>
