The answer URL is an https URL you host. When a person is connected, Unpod fetches it and
runs the instructions you reply with, in XML or JSON. The format is the same for outbound
and inbound calls.

## When Unpod calls your answer URL

| Call | Where you set the answer URL |
| --- | --- |
| Outbound | `answer_url` (and `answer_method`, `POST` or `GET`) on `create` or `add_participant` |
| Inbound | The number's config. See [Incoming Calls](/telephony/apis/incoming-calls) |

On an outbound leg, Unpod runs your instructions once that person connects, instead of
just bridging them:

<CodeGroup>
```python Python
from unpod import Client

with Client() as client:
    call = client.telephony.calls.create(
        "+919000000001",  # your Unpod number
        "+919000000002",  # who to call
        answer_url="https://your-app.example.com/answer",
        answer_method="POST",
    )
    print("calling", call.call_id)
```

```bash cURL
curl -s -X POST "https://unpod.ai/api/v2/platform/sbc/v1/calls" \
  -H "Authorization: Token $UNPOD_PLATFORM_TOKEN" -H "Org-Handle: $UNPOD_ORG_HANDLE" \
  -H "Idempotency-Key: $(uuidgen)" -H "Content-Type: application/json" \
  -d '{"from": "+919000000001", "to": "+919000000002",
       "answer_url": "https://your-app.example.com/answer", "answer_method": "POST"}'
```
</CodeGroup>

The answer URL must be public https, or you get `400 invalid_url`.

## What Unpod sends

On an inbound call, your answer URL receives:

| `ev.event` | `ev.call_status` | When |
| --- | --- | --- |
| `StartApp` | `ringing` | A new call. Reply with instructions |
| `Hangup` | `completed`, `busy`, `no-answer`, `failed` | The call ended. Also carries `Duration`, `StartTime`, `EndTime` |
| `RecordStop` | - | Recording ready at `ev.recording_url` |

Each `StartApp` also carries `CallUUID` (`ev.leg_id`), `From` (`ev.from_`), `To`,
`Direction=inbound` and `SessionStart` (`ev.raw["SessionStart"]`).

Every request is signed with your org's secret. Verify and parse it with
`parse_call_event` - see [Webhooks](/telephony/apis/webhooks).

## Reply with XML or JSON

Plivo-style XML:

```xml
<Response>
    <Record/>
    <Dial><Number>+919000000003</Number></Dial>
</Response>
```

```xml
<Response>
    <Speak>All our agents are busy.</Speak>
    <Hangup/>
</Response>
```

Or JSON:

```json
{"actions": [{"type": "record"}, {"type": "dial", "number": "+919000000003"}]}
```

| Verb | Does |
| --- | --- |
| `dial` | Connect the person to a number |
| `play` | Play an https audio URL |
| `speak` | Text-to-speech |
| `wait` | Pause |
| `record` | Record the call |
| `hangup` | End the call |

Every audio URL must be public https. An empty 2xx body means "continue with static
routing".

Pick the voice and language for one `Speak`:

```xml
<Response>
    <Speak voice="VOICE_ID" language="LANGUAGE_CODE">Your order has shipped.</Speak>
    <Hangup/>
</Response>
```

## A minimal answer server

```python app.py
import os
from fastapi import FastAPI, HTTPException, Request, Response
from unpod.telephony import WebhookSignatureError, parse_call_event

SECRET = os.environ["UNPOD_WEBHOOK_SECRET"]
GREETING = "<Response><Speak>Hello from Unpod.</Speak><Hangup/></Response>"
app = FastAPI()


@app.post("/answer")
async def answer(request: Request):
    try:
        ev = parse_call_event(await request.body(), request.headers, secret=SECRET)
    except WebhookSignatureError:
        raise HTTPException(401)

    if ev.event == "StartApp":  # someone is connected: reply with instructions
        return Response(GREETING, media_type="application/xml")
    return Response(status_code=200)  # Hangup / RecordStop: acknowledge
```

It rejects unsigned requests, speaks to every new call and returns 200 for every other
event. Run and expose it as in the
[Quick Start](/telephony/apis/quickstart#receive-your-first-call). To route callers to
free agents, see [Incoming Calls](/telephony/apis/incoming-calls).

## Timeouts and fallback

Set these on the number's config ([Incoming Calls](/telephony/apis/incoming-calls)):

| Field | Meaning |
| --- | --- |
| `answer_timeout_ms` | 500-10000. How long Unpod waits for your reply |
| `answer_fallback` | `static_routing` (default) or `reject_503` when your app does not answer |

An empty 2xx body is not a failure: Unpod continues with static routing.

## Serve a static file

No server needed: host a fixed XML file on any public https host, then pass
`answer_url="https://cdn.example.com/greeting.xml"` and `answer_method="GET"` to `create`.
Every call runs the same instructions, which suits
[Call Blasting](/telephony/apis/call-blasting).

```xml greeting.xml
<Response>
    <Speak>Hello! Your order has shipped.</Speak>
    <Hangup/>
</Response>
```
