## Getting Started

Analytics and Reporting refers to the tools and dashboards that track, measure, and visualize the activity and performance of a Space or AI agent. This includes metrics like user interactions, engagement, call outcomes, document usage, and overall agent effectiveness, helping teams make data-driven decisions and optimize workflows.

Unpod dashboard provides you with two options to see the reports and analyze the performance of your business. Both the options are available in Space View.

---

## Call Logs

This option is available in the Space View. Open the three-dot menu in the space header and choose **Call Logs**. If you want to download all the details of the calls executed on the space in the form of CSV, you can download it from here.

When you click on Call Logs, a drawer opens where you can fill in the following filters (all optional):

- **From** / **To** - Starting and ending date and time within which you need the report.
- **Run IDs** - Wherever you initiate a call, the dashboard will consider this as a task and create a run id for the same. You can choose one or more run ids for which you want the report.
- **Agents** - If you have multiple agents for your organization, then select the agents for which you want the report.
- **User** - If you want the report for a particular user, you can select the name of the user.
- **Contact Numbers (comma-separated)** - Limit the report to specific phone numbers.
- **Document ID** - Limit the report to one document in the space.

Once you enter all the details, click on Download to get the CSV file.

The CSV file contains structured data which you have mentioned while setting up the Analysis settings of the Agent.

## Analytics

This option is available in Space View. You can access it from **Analytics** in the left sidebar of the dashboard. The Analytics tab shows insights and performance metrics related to activity within the Space, including engagement, usage trends, and key statistics. It helps users track progress and measure impact across discussions, calls, and content.

Once you click on Analytics tab, you will be redirected to the analytics dashboard.

The dashboard shows:

- **Volume metrics** - Numbers used, Minutes Consumed (each call is rounded up to the nearest minute), Voicemails, Avg Minutes Consumed, and Total cost / Average cost when calls carry a charge. Filters at the top narrow every number on the page.
- **Call Status** - Where all calls sit right now: Scheduled, Connected, Not connected and Failed, each with its share of all dialed calls.
- **Structured Data** - Select an output to see its goal metrics, plus Sentiment and End Call Reason.
- **Call Activity Peak Times** - Total calls and connected calls by hour, with the busiest window highlighted.
- **By Agent / By Number** - A table of calls, connected, not connected, failed, billable minutes and cost per agent or per number.
