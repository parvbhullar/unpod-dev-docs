## Getting Started

Unpod Agents are AI-powered assistants that handle calls, chats, and tasks. With an agent, you can decide how it interacts with users, what knowledge it accesses, and how it communicates over the phone.

---

## Create an Agent

1. Log in to the [dashboard](https://unpod.ai) and click **AI Studio** in the left sidebar.
2. In the **Agents** list, click **+**. This opens the agent setup flow:
   - **Start** - describe what the agent should do, pick a template, or fetch details from your website URL, then click **Generate Agent**.
   - **AI Identity** - review the generated **Name**, **Greeting** and **Behavior script**, then click **Continue**. This creates the agent.
   - **Voice Profile** - pick a voice profile and click **Continue**.
   - **Launch** - review the summary and click **Launch profile**.
3. You land on the agent's page in AI Studio. The agent also appears in the **Agents** list on the left.

See [Create Your AI Identity](/platform/onboarding) for each screen of the setup flow.

## The Agent Page

The agent page has these tabs:

| Tab | What it holds | Details |
|---|---|---|
| **Persona** | Greeting message, conversation mode (Prompt, Playbook or SDK), engine, tools and knowledge bases | [Persona](/platform/studio-view/persona) |
| **Voice Profile** | Saved voice profile, LLM (AI provider, AI model, Max Tokens, Temperature), transcriber, voice and config. Voice agents only | [Voice Profile](/platform/studio-view/voice-profile) |
| **Advanced** | Context (spam detection, memory, recording), Follow-up & Handover, Calling Hours, Speaking Plan. Voice agents only | [Advanced](/platform/studio-view/advance) |
| **Analysis** | Post-call summary, success evaluation and structured data | [Analysis](/platform/studio-view/analysis) |
| **Integration** | Webhook and Google Sheet Sync | [Integration](/platform/studio-view/integration) |
| **Identity** | Description, avatar, privacy, category, tags, purpose, contact and social links | [Identity](/platform/studio-view/identity) |

Each tab has a section list on the left; click a section to edit it on the right, then click **Save** at the bottom right of the tab. Each tab saves on its own.

At the top right of the agent page:
- **Talk To Agent** - test the agent in the browser.
- **Publish** - publish the agent.
- The **⋮** menu - **Test Agent**, **Duplicate Agent**, **Copy Handle** and **Delete**.

The agent page has no Telephony tab. To give the agent a phone number, use **Telephony** in the left sidebar; see [Telephony](/platform/studio-view/telephony).

## Typical Setup Order

1. **Persona** - check the **Greeting message**, then write the system prompt under **Prompt** (or switch to its **Template** tab and click **Select template** to start from a template). Attach knowledge bases under **Knowledge**: click **Add**, select them, click **Add (n)**, then **Save**. To create a knowledge base first, see [Knowledge Base](/platform/studio-view/knowledge-base).
2. **Voice Profile** - pick a saved profile with **Manage Profiles**, or set the **LLM**, **Transcriber** and **Voice** sections by hand.
3. **Advanced** - set follow-ups, **Instant Redial**, handover, **Calling Hours** and the **Speaking Plan**.
4. **Analysis** - set how calls are summarized and evaluated, and which structured data to extract.
5. **Integration** - add a webhook or a Google Sheet to receive call data.
6. Click **Publish** at the top right. **Your AI Agent is now ready to use!**
