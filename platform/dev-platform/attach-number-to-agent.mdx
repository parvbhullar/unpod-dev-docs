## Overview

The platform telephony plane (`client.telephony.*`) maps your phone numbers to
voice **agents** on backend-core's `/api/v2/platform/telephony/*` surface. The
primary flow is **attach a number to an agent** - what telephony calls the
**Leg-B** termination (Unpod's SuperSBC routes the inbound call through to your
agent on LiveKit).

You **list** your org's numbers, then **attach** one or many to an agent. The
underlying voice bridge is resolved for you (hidden) - you work with numbers and
agents, not bridges.

<Note>
This plane (`client.telephony.*`) is distinct from the Speech Stack management
plane at [`client.numbers`](/speech-stack/numbers). The telephony plane is
`Org-Handle`-scoped and needs your API key and org handle (Token auth) - a Bearer
`UNPOD_API_KEY` alone is refused.
</Note>

---

## Concepts

| Concept | What it is |
|---|---|
| **Leg B (agent attach)** | SuperSBC → agent/LiveKit. The **primary** flow - `numbers.attach(..., agent_id=...)`. |
| **Leg A (BYO carrier)** | Your own SIP carrier → SuperSBC. The carrier leg is the hardcoded SuperSBC default today; bringing your own carrier (`client.telephony.trunks.*`) is **future/beta**. |
| **`agent_id`** | The handle of an agent your org owns. **Optional** - attach without one, then bind an agent with `client.numbers.agent.change` (see below). |
| **Bridge** | The voice bridge a number rides on. **Auto-resolved and hidden** - one number maps to one bridge. |

## Authenticate

The telephony plane is org-scoped. Export your host, API key and org handle
([Account & keys](/home/account-and-keys)); a client with no arguments reads them:

```bash
export UNPOD_BASE_URL=https://unpod.dev
export UNPOD_PLATFORM_TOKEN=<your-api-key>
export UNPOD_ORG_HANDLE=<your-org-handle>
```

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:
        numbers = await client.telephony.numbers.list()
        for n in numbers:
            print(n.number, n.status)

asyncio.run(main())
```

Every verb on this plane takes the **E.164 number** - the internal id is not exposed.

| Field | Type | Description |
|---|---|---|
| `number` | `str \| None` | E.164 format, e.g. `+14155550100` |
| `status` | `str \| None` | `not_assigned` (attachable), `assigned`, or `closed` |

## Attach Numbers to an Agent

Map one or more numbers to an agent **by E.164 number** (not id - Django resolves
it). The bridge is resolved automatically; each number reports its own outcome
(partial-success), so one bad number never fails the rest.

With the default `attach_type="agent"`, `agent_id` must be the handle of an agent
your org owns. Otherwise the whole request fails with `400` `Agent not found for
this organization.` and nothing is attached. (`attach_type="pipeline"` skips this
check.)

`list()` also returns numbers your org already attached, so pick the ones whose
`status` is `not_assigned`:

```python
import asyncio
from unpod import AsyncClient

async def main():
    async with AsyncClient() as client:
        nums = await client.telephony.numbers.list()
        free = [n.number for n in nums if n.status == "not_assigned"]
        if not free:
            raise RuntimeError("No free numbers")
        res = await client.telephony.numbers.attach(
            free[:2],
            agent_id="asst_sales",
        )
        print(res.agent_id, res.message)
        for r in res.numbers:
            print(r.number, r.connection_state, "ok" if r.ok else r.error)

asyncio.run(main())
```

### Result fields

| Field | Type | Description |
|---|---|---|
| `agent_id` | `str \| None` | The agent the numbers were bound to (echoes the request). |
| `numbers` | `list[NumberResult]` | Per-number outcome (see below). |
| `message` | `str \| None` | Human-readable summary. |

Each `NumberResult`:

| Field | Type | Description |
|---|---|---|
| `number_id` | `int` | The number's ID. |
| `number` | `str \| None` | E.164, on success. |
| `connection_state` | `str \| None` | Lifecycle state (e.g. `NOT_LINKED`, `PENDING_VERIFY`). |
| `agent_id` | `str \| None` | The bound agent, on success. |
| `ok` | `bool` | `True` if this number was attached. |
| `error` | `str \| None` | Why it failed, when `ok` is `False`. |

<Note>
The agent attach returns the per-number **lifecycle** - there is no carrier
`origin_endpoint`. That belongs to the BYO-carrier (Leg-A) path below.
</Note>

### `agent_id` is optional

Omit `agent_id` to wire a number for agent use without binding an agent yet.
Don't call `attach` again to bind one: the number is already attached, so a second
`attach` fails with `400` `No valid unassigned numbers found.` Change the agent on
the attached number instead:

```python
# provision now, bind later
await client.telephony.numbers.attach(["+14155550100"])
# ...later: move the attached number to an agent
await client.numbers.agent.change("+14155550100", "asst_sales", attach_type="agent")
```

`numbers.agent.change(number, agent_id, *, attach_type=None)` defaults to
`attach_type="pipeline"` (a Speech Stack agent). For an agent handle like the one
above, pass `attach_type="agent"`, or the call fails with `404` `Agent not found.`
For a Speech Stack agent you can also use `client.agents.update(agent_id, number=...)`
(it sends no `attach_type`, so it takes the `"pipeline"` default). Over HTTP, use
`POST /api/v2/platform/telephony/numbers/reassign/` with
`{"number": "+14155550100", "agent_id": "asst_sales"}` (`attach_type` is `agent` by
default there). A number attached without an agent can be moved this way. It fails
with `409` and a `code`:

| `code` | Why |
|---|---|
| `not_attached` | The number is free but not attached yet. Use `attach` |
| `unsupported_termination` | The number doesn't end on an agent or pipeline, for example a `human_call` number. Detach it first |
| `number_in_use` | A call is in progress on the number |

Detach first if you want to re-attach.

### Attach to a pipe instead of an agent

Pass `attach_type="pipeline"` with a `pipe_id` to terminate the number on a
Speech Pipe rather than an agent. `attach_type` defaults to `"agent"`. A pipeline
attach without `pipe_id` fails with `400` (over HTTP the field is
`supervoice_agent_id`; `pipe_id` is an accepted alias).

```python
await client.telephony.numbers.attach(
    ["+14155550100"], attach_type="pipeline", pipe_id="pipe_xyz",
)
```

### Attach for your own app (`human_call`)

Pass `attach_type="human_call"` when no agent answers: your app places and answers
calls with the Telephony APIs. Leave out `agent_id`; passing one fails with `400`.

```python
await client.telephony.numbers.attach(["+14155550100"], attach_type="human_call")
```

See [Get a Number](/telephony/apis/numbers) for every attach option and error.

## Detach Numbers

Release numbers by E.164 number - the inverse of `attach`. The termination,
agent, and pipe are read from the stored record. The number is **released, not
deleted**, so it stays available for a later re-attach.

```python
res = await client.telephony.numbers.detach(["+14155550100"])
for r in res.numbers:
    print(r.number, "released" if r.ok else r.error)
```

## Bring Your Own Carrier (Leg A) - Future / Beta

Bringing your own SIP carrier (`client.telephony.trunks.*`) wires the **Leg-A**
carrier leg. Today that leg is the hardcoded SuperSBC default, so this surface is
**future/beta** - prefer the agent attach above for production. When enabled, the
flow is: create a trunk, attach numbers, and point your carrier at the returned
origin endpoint.

```python
# future / beta - BYO SIP carrier (Leg A)
trunk = await client.telephony.trunks.create(
    name="My Carrier", sip_url="sip:carrier.net",
    username="u", password="p", source_ips=["203.0.113.10"],
)
res = await client.telephony.trunks.attach_numbers(trunk.id, number_ids=[1, 2])
print(res.origin_endpoint.ingress)  # point your carrier here
```

## Common Patterns

### Attach the first available number to an agent

```python
import asyncio
from unpod import AsyncClient

async def attach_first(agent_id: str) -> None:
    async with AsyncClient() as client:
        nums = await client.telephony.numbers.list()
        free = [n.number for n in nums if n.status == "not_assigned"]
        if not free:
            raise RuntimeError("No free numbers")
        res = await client.telephony.numbers.attach([free[0]], agent_id=agent_id)
        row = res.numbers[0]
        print("attached" if row.ok else f"failed: {row.error}", free[0])

asyncio.run(attach_first("asst_sales"))
```

### Attach many numbers to one agent

```python
import asyncio
from unpod import AsyncClient

async def attach_all(numbers: list[str], agent_id: str) -> None:
    async with AsyncClient() as client:
        res = await client.telephony.numbers.attach(numbers, agent_id=agent_id)
        ok = [r.number for r in res.numbers if r.ok]
        bad = [(r.number_id, r.error) for r in res.numbers if not r.ok]
        print("attached:", ok)
        if bad:
            print("failed:", bad)

asyncio.run(attach_all(["+14155550100", "+14155550101"], "asst_sales"))
```
