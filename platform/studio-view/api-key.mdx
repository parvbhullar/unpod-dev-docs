## API Key

An API key is a secure, unique identifier used to authenticate and authorize an application or agent to access specific APIs and services.

To generate an API key:

1. Click **Settings** at the bottom of the left sidebar.
2. In the settings menu, under **Access**, click **API keys**.
3. Click **Generate New**.

The key appears in the table with its **Created** date. The key is hidden by default: click the eye button to show it, and the copy button to copy it. To delete a key, use the delete action in the **Actions** column.

**Generate New** is disabled while you already have a key. Delete the existing key first if you need a new one.

The **Access** section is shown only to the workspace owner.
