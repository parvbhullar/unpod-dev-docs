## Telephony

The agent page in AI Studio has no Telephony tab. You connect a phone number to an agent from the **Telephony** section in the left sidebar:

1. Open **Telephony → Numbers**.
2. Select the number you want the agent to answer.
3. Under **Connect to**, select the agent to route this number to, then click **Connect agent**.

Calls to that number now route to the selected agent. Each number connects to one agent.

To connect a number from code instead, see [Attach a Number to an Agent](/platform/dev-platform/attach-number-to-agent).

After the Voice Profile tab, continue with the next tab, [Advanced](/platform/studio-view/advance).
