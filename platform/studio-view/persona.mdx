## Persona

The **Persona** tab defines how your agent starts the conversation, how it behaves (its prompt or playbook), which tools it can call and which knowledge bases it can use. It is the first tab that opens on an agent.

The section list on the left is grouped like this:
- **Engine** - at the top.
- **GREETING** - **Greeting message**.
- **CONVERSATION MODE** - **Prompt**, **Playbook** and **SDK**.
- **SETTING** - **Tools** and **Knowledge**.

Click a section to edit it on the right. When you're done, click **Save** at the bottom right of the tab.

### Greeting message

The first line spoken when a session starts. For example:

"Hello! How can I assist you today?"

### Conversation Mode

The conversation mode decides what drives the agent. Exactly one mode is active at a time: **Prompt**, **Playbook** or **SDK**. The active one is marked **Active**; the others show a lock. To switch, open the section you want, click **Set as Conversation mode**, and click **Save**.

#### Prompt

Write the system prompt that defines the agent's behavior: its identity, style (for example "professional", "friendly" or "empathetic" — there is no separate tone selector), response guidelines, and the tasks it should complete. Clear instructions give more exact and reliable answers.

The **Prompt** section has two tabs at the top right:
- **Prompt** - write or edit the system prompt yourself.
- **Template** - start from a ready-made prompt:
  1. Click **Select template**.
  2. In the **Select template** drawer, pick the template card that best fits your business.
  3. The template's prompt is copied into the system prompt. The template you picked is shown with **Change** and **Remove** options.
  4. Review and edit the prompt on the **Prompt** tab if needed, then click **Save**.

Picking a template copies its prompt; it doesn't generate a new one.

#### Playbook

Run the agent from a playbook instead of a prompt. The switch at the top right of the section has two options:
- **Endpoint** - link an existing playbook. Click **Select playbook**, choose one from **My Playbooks** or **Defaults** in the drawer, then click **Save**. Use **Sync latest changes** to pull the playbook's latest version. While a playbook is linked, its content is read-only here; use **Edit in Playground** to change it.
- **Prompt** - write the playbook yourself in the editor (**Open in full view** gives a larger editor).

#### SDK

Choose the speech agent the playbook runs on. Click **Select agent** and pick the agent in the drawer; **Change** and **Remove** replace or clear it.

### Engine

The calling engine the agent runs on (**Stable** or **Dev**). Click **Change** to pick a different one.

### Tools

Functions the agent can call during a conversation, such as an HTTP request to your API. Click **Add tool** to create one, **Import Tool** to import tool definitions, or **Export Tools** to export them. Each tool has a **Tool ID**, a **Description** the model reads to decide when to call it, its **Parameters**, and the request details.

### Knowledge

Attach knowledge bases the agent can retrieve answers from. Click **Add**, select one or more knowledge bases in the **Select knowledge bases** drawer, click **Add (n)**, then click **Save**. See [Attach a Knowledge Base to an Agent](/platform/studio-view/knowledge-base#attach-a-knowledge-base-to-an-agent).

After saving, continue with the next tab, [Voice Profile](/platform/studio-view/voice-profile).
