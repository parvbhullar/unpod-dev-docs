## Advanced

The **Advanced** tab controls how the agent behaves around a call: spam and memory settings, automatic follow-ups and redials, human handover, when the agent may call, and when it should stop talking. It is only shown for voice agents.

The sections in the left list are **Context**, **Follow-up & Handover**, **Calling Hours** and **Speaking Plan**.

### Context

Spam detection, memory and recording:
- **Spam Detection** - the assistant automatically detects spam calls and blocks suspicious callers.
- **Enable Memory** - the assistant uses previous conversation memories to understand the user's context, so replies stay consistent across calls instead of treating each call as new.
- **Enable Recording** - records conversations for quality assurance and training. If recording isn't included in your workspace's plan, the switch is disabled with the note "Recording is not enabled for your workspace. Contact support to add it."
- **RealTime Evaluation** - tracks real-time evaluation results and response latency during calls.
- **Duplicate lead** - when on, a call can't be triggered on the same number again for 24 hours.
- **ISD calls** - turn this on to allow international calling on your agent.

### Follow-up & Handover

Follow-ups, redial, SMS notifications and handover:
- **Enable Followup** - the assistant schedules a follow-up with the user automatically. When on, a **Followup Instructions** box appears where you describe when and how to follow up.
- **Instant Redial** - the assistant redials if the call is missed or dropped.
- **Notify Via SMS** - if the assistant can't reach the user by call, it informs them by SMS.
- **Handover Number** - forwards the call to a human when handover is triggered. When on, you can set:
  - **Instant Handover** - transfer the call to a human agent immediately.
  - **Phone Number** - the number calls are forwarded to.
  - **Handover Instructions** - when the agent should hand over.
  - **Role** - the role of the person who takes the call.

### Calling Hours

The days and time ranges when the agent can place calls. Choose the days under **Select Days**, then set **Time Ranges** with a **Start time** and **End time**. Click **Add Range** to add more slots. At least one time slot is required.

### Speaking Plan

Endpointing thresholds that decide when the assistant stops talking because the caller has started speaking:
- **Number of words** - how many words the caller has to say before the assistant stops.
- **Voice seconds** - how many seconds the caller can speak before the assistant stops.
- **Back off seconds** - how many seconds to wait before the assistant starts talking again after an interruption.
