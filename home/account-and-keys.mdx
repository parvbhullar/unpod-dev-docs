Every developer path needs the same two things: an Unpod org, and the right
credential for the surface you call. This page gets you both in a few
minutes.

<Steps>
<Step title="Request access">

Open [unpod.ai](https://unpod.ai/), click **Request a Call Back**, fill in the
form and submit it. Your login credentials arrive by email.

</Step>
<Step title="Sign in and create your hub">

Click **Sign In** on [unpod.ai](https://unpod.ai/). On first login you create
a hub for your organization:

| Field | What to enter |
|---|---|
| **Hub name** | Your organization's name |
| **Domain name** | Your org's domain, e.g. `acme.com` |
| **Privacy type** | **Private** (only people on your domain see it) or **Public** |
| **Type of account** | The option closest to how you use Unpod |

</Step>
<Step title="Generate an API key">

1. Click **Settings** at the bottom of the left sidebar.
2. Under **Access**, click **API keys**.
3. Click **Generate New**, then copy the key.

Only the workspace owner sees **Access**. You can hold one key at a time:
delete the old key to generate a new one.

</Step>
<Step title="Put both in your environment">

```bash .env
UNPOD_BASE_URL="https://unpod.ai"
UNPOD_SERVICE_BASE_URL="https://unpod.ai"   # bare host - no path
UNPOD_PLATFORM_TOKEN="..."                  # the API key from step 3
UNPOD_ORG_HANDLE="your-org"                 # your organization's domain handle
```

`import unpod` loads `.env` from the working directory. The SDK sends them as
`Authorization: Token <key>` and `Org-Handle: <handle>`; call the REST API
directly with the same two headers.

</Step>
</Steps>

## Which credential is which

Unpod's credentials are not interchangeable:

| You are calling | Host | Auth | Where it comes from |
|---|---|---|---|
| **Python SDK** (agents, numbers, calls) | `unpod.ai` | `UNPOD_PLATFORM_TOKEN` + `UNPOD_ORG_HANDLE` | API key + org handle, above |
| **AgentRunner** (your own brain) | the orchestrator | `UNPOD_PLATFORM_TOKEN` + `UNPOD_ORG_HANDLE` | API key + org handle, above |
| **Platform REST API** | `unpod.ai` | `Authorization: Token` + `Org-Handle` headers | API key + org handle, above |
| **Chat API** (your agent as a model) | `inference.unpod.ai` | `Authorization: Bearer` endpoint key | Playground → **Deploy as Endpoint** |

Token auth (`UNPOD_PLATFORM_TOKEN` + `UNPOD_ORG_HANDLE`) wins over
`UNPOD_API_KEY` when both are set. Analytics and telephony calls need token
auth, so use the token.
